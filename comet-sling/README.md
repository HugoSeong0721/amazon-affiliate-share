# 코멧 슬링 (Comet Sling — One-Touch Orbit Dash)

한 손가락으로 혜성을 궤도에 걸었다 놓으며 위로, 위로 던져 올리는 **실시간 아케이드**.
누르면 가까운 앵커에 붙어 돌고, 놓으면 접선 방향으로 날아간다. 그게 조작의 전부다.

## 왜 이 게임인가 — 분위기부터 다르게

[자석 구슬](../magnet-ball-sort/README.md) 이후의 시도들(페인트 믹스, 주차장 탈출)은
메커니즘은 달랐지만 **골격이 같았다**: 정지된 보드, 차분한 파스텔, 턴제 퍼즐,
135레벨 + 별점 + 여정 지도. 그래서 셋을 나란히 놓으면 같은 게임의 스킨처럼 보였다.

코멧 슬링은 골격 자체를 뒤집는다:

| | 자석 구슬 · 페인트 믹스 · 주차장 탈출 | **코멧 슬링** |
|---|---|---|
| 시간 | 턴제 — 생각하는 동안 멈춰 있다 | **실시간** — 손을 떼는 타이밍이 곧 실력 |
| 감정 | 차분한 정리의 만족감 | **속도·긴장·아슬아슬함** (니어미스 보너스) |
| 구조 | 레벨 135개 + 별점 | **엔드리스** — 죽고, 기록 갱신에 도전 |
| 실패 | 막다른 길 없음, 되돌리기 | **죽음이 있다** — 대신 재시작이 0.6초 |
| 화면 | 파스텔 낮, 정적인 보드 | **깊은 우주의 밤, 네온 글로우, 흐르는 별** |
| 조작 | 탭 (이산적 선택) | **홀드 & 릴리즈** (연속적 타이밍) |
| 소리 | 딸깍·퐁 (장난감) | **휘익·지잉·쿵 (속도)** |

바뀌지 않은 것은 이 시리즈의 신조뿐이다: **설명하지 않는다**, 손맛이 먼저다,
레벨(트랙)은 코드가 검증한다, 광고는 언제 안 띄울지가 더 중요하다.

## 설계 원칙: 설명하지 않는다 (조작이 하나뿐이라 배울 게 없다)

튜토리얼 문구가 없다. 첫 화면에는 혜성과, 위에서 빛나는 앵커와,
**차오르는 링을 두른 손가락 힌트** 하나뿐이다 (첫 릴리즈에 성공하면 영원히 사라진다).

- 누르고 있으면 → 사거리 안 앵커에 **자석처럼 붙어 돈다** (점선 캡처 링이 미리 숨쉰다)
- 놓으면 → **돌던 방향 그대로** 날아간다 (물리가 직관과 일치한다 — 접선 방향)
- 회전 방향은 진행 방향을 잇도록 자동으로 정해진다 — 거스르는 느낌이 없다

죽는 방법은 세 가지: 벽, 소행성, 추락. 전부 화면에 보이는 것들이라 설명이 필요 없다.

## 점수

- **높이**가 점수의 뼈대 (4유닛 = 1점)
- 소행성을 아슬아슬하게 스치면 **니어미스 +25** — 안전한 길과 빠른 길이 갈라진다
- 최고 기록은 기기에 저장된다 (`cms.best` / `cms.runs` / `cms.taught`)

## 트랙은 코드가 보증한다

퍼즐 형제들이 "솔버로 최소 수를 재서" 레벨을 보증했다면, 여기서는 **생성 불변식**으로
플레이 가능성을 보증한다. 시드 RNG로 무한 생성되는 트랙이 항상 지키는 것:

- 소행성은 어떤 앵커의 **최대 궤도 반지름 밖**에 있다 → 궤도를 도는 중에는 절대 안 죽는다
- 소행성은 **이웃 앵커 사이 직선**을 막지 않는다 → 이상적인 비행선은 언제나 열려 있다
- 앵커는 최대 궤도가 벽 안에 들어오는 범위에만 놓인다

그래서 죽음은 언제나 릴리즈 타이밍의 결과지, 트랙의 횡포가 아니다.
난이도는 높이에 따라 속도(32→100)와 소행성 밀도만 단조 증가시킨다.
초반(높이 800까지)에는 릴리즈 방향에 위쪽 성분을 섞어 주는 **에임 어시스트**가 있어
타이밍이 어긋나도 대충 위로는 간다 — 배우는 동안 벽이 덜 아프고, 실력이 늘면 알아서 사라진다.

```
node --test comet-sling/tests/*.mjs            # 결정론 + 불변식 + 물리 검증 (12 tests)
node comet-sling/tools/build-single-file.mjs   # 자립형 HTML 한 파일 (dist/, 37KB)
```

## 실행

정적 서버로 레포 루트를 서빙하고 `/comet-sling/` 접속:

```bash
python3 -m http.server 8000
# → http://localhost:8000/comet-sling/
```

- `?seed=42` — 트랙 고정 (리플레이·테스트)
- `?noads` — 광고 끄기
- `?debug` — 자동화 훅 `window.__cms` (state, press/release, kill, newRun)
- 데스크톱에서는 스페이스바 홀드로도 플레이된다

## 광고

형제들과 같은 뼈대(`ads.js`)를 엔드리스에 맞게 단위만 바꿨다: 처음 5런은 무광고,
그 뒤 세 런마다, 최소 60초 간격, **런 도중에는 절대**, 그리고 **20초를 못 넘긴 짧은 런
뒤에는 안 띄운다** — 연속 즉사에 광고까지 겹치는 게 이 장르 최악의 이탈 경로다.

## 구성

| 파일 | 역할 |
|---|---|
| `engine.js` | 순수 로직 — 시드 RNG, 무한 트랙 생성, 고정 스텝(1/120s) 물리, 충돌, 점수. 결정론이 계약이다 |
| `game.js` | 모드 전환(ready→running→dead), 입력, 최고 기록 저장 |
| `render.js` | 캔버스 — 패럴랙스 별밭, 네온 글로우, 트레일, 파티클, 화면 흔들림 |
| `audio.js` | WebAudio 신시사이저 — 파일 없이 코드로 만든 효과음 |
| `ads.js` | 전면 광고 자리 + 런 단위 빈도 규칙 |
| `main.js` | 부트스트랩 — DOM, 포인터/키 입력, rAF 루프, 디버그 API |
| `tests/engine.test.mjs` | 결정론 · 트랙 불변식(시드 200개) · 난이도 단조성 · 물리 |
| `tools/build-single-file.mjs` | 자립형 HTML 빌드 (공유 번들러 재사용) |
