# 택시 아웃 (Taxi Out — Parking Escape)

꽉 막힌 주차장에서 차들을 밀어 택시를 빼내는 클래식 언블록 퍼즐 (러시아워 스타일).

**손님을 태운 택시가 주차장에 갇혔다. 차들을 비켜 주면 집에 갈 수 있다.**
5레벨마다 승객 한 명이 집에 도착하고, 마지막 승객은 왕관을 쓰고 있다.

[자석 구슬](../magnet-ball-sort/README.md)과 같은 느낌 — 설명 없이 보면 아는 목표,
satisfying한 손맛, 단계별 레벨 진행 — 을 전혀 다른 메커니즘 위에 다시 지은 게임이다.

## 설계 원칙: 설명하지 않는다 (이번엔 손이 배운다)

튜토리얼 문구도, 목표 표시도 없다. 화면을 보면 목표가 그냥 보인다 —
**꽉 막힌 주차장, 벽에 뚫린 구멍, 그 높이에서 깜빡이는 택시.**

자석 구슬이 규칙을 애니메이션으로 전달했다면, 이 게임은 **손끝으로** 전달한다:

- 차를 잡으면 살짝 떠오르고, **자기 축을 따라서만** 손을 따라온다
- 칸 경계를 지날 때마다 **딸깍** — 손가락에 눈금이 느껴진다
- 막힌 곳에서는 러버밴드처럼 저항하다가 **쿵** 하고 멈춘다 (화면이 미세하게 흔들리고 먼지가 튄다)
- 놓으면 가장 가까운 칸으로 스프링처럼 **딱** 붙는다

"차는 자기 방향으로만 움직인다"를 글로 읽을 필요가 없다 — 3초 만져보면 안다.
첫 레벨만 유령 손끝이 미는 방향을 반복해서 보여준다 (한 번의 드래그로 끝난다).

## 규칙

- 차를 끌어 축 방향으로 미끄러뜨린다 (한 번의 미끄러짐 = 한 수, 거리 무관)
- 노란 택시가 오른쪽 출구로 나가면 클리어
- 모든 수는 되돌릴 수 있으므로 **막다른 길이 없다** — 되돌리기(↩︎)는 오직 별점 재도전용
- **힌트**(💡) — 지금 상태에서 솔버가 찾은 다음 최적 수를 손끝으로 짚어준다.
  참고 답안의 두 배(최소 +6수)를 넘기도록 헤매면 힌트/처음부터 버튼이 담긴
  도우미 패널이 먼저 손을 내민다 (레벨당 한 번, 보드를 만지면 조용히 사라진다)

## 진행과 보상

- **별 1~3개** — 참고 답안(BFS 솔버가 찾은 최소 수) 안에 풀면 3개, 1.4배 안이면 2개, 그 밖은 1개
- **여정 지도** (☰) — 길을 따라 늘어선 120개 레벨. 5레벨마다 승객이 집에 도착한다.
- 진행·별점은 기기에 저장된다 (`pke.level` / `pke.cleared` / `pke.stars`)

## 난이도는 측정한다

무작위 배치에서 어려운 판(par 10+)은 드물다. 그래서 "목표 난이도에 맞춰 생성"이 아니라
**많이 만들고 골라낸다**: 시드 1만 5천 개를 돌려 후보 풀을 만들고, 판마다 BFS 솔버로
최소 수를 잰 뒤, 설계된 곡선(1수 → 28수, 단조 증가)에 가장 가까운 판을 고른다.
곡선은 실플레이 피드백으로 한 번 고쳤다 — 지수 곡선(t^1.35)은 20레벨까지 너무 쉽다가
갑자기 어려워져서, 지금은 선형+약한 이차 혼합으로 10레벨 안에 2수, 20레벨쯤 4수에 닿는다.
출구 행의 가로차는 영원히 비킬 수 없어 판을 영구히 막으므로 생성 단계에서 금지한다.

```
node parking-escape/tools/bake-levels.mjs   # 레벨 다시 굽기 (~40초)
node --test parking-escape/tests/*.mjs      # 엔진 + 구운 레벨 검증
node parking-escape/tools/build-single-file.mjs  # 자립형 HTML 한 파일 (dist/)
```

## 광고

자석 구슬과 같은 정책( `ads.js` ): 처음 3판은 무광고, 그 뒤 두 판마다, 최소 45초 간격,
퍼즐 도중·다시하기에는 절대 안 뜬다. `?noads`로 완전히 끈다. `?debug`로 자동화 훅(`window.__pke`)이 열린다.

## 구성

| 파일 | 역할 |
|---|---|
| `engine.js` | 순수 로직 — 점유 격자, 이동 구간, BFS 솔버, 시드 생성기, 직렬화 |
| `levels.js` | 후보 풀 스펙 + 목표 난이도 곡선 |
| `levels-data.js` | 구운 레벨 120개 (자동 생성 — 직접 수정 금지) |
| `render.js` | 캔버스 렌더러 — 드래그 물리(스프링·러버밴드·디텐트), 탈출 연출 |
| `game.js` | 컨트롤러 — 수 판정, 별점, 여정, HUD |
| `audio.js` / `ads.js` | WebAudio 효과음 / 전면 광고 자리와 빈도 규칙 |
