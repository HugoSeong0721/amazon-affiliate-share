# 토치 다이브 (Torch Dive — One More Floor)

매일 자정에 새로 파이는 던전을 횃불 3개로 내려가는 **푸시-유어-럭(push-your-luck)**.
층마다 문이 4개, 문 뒤에 무엇이 있는지 게임이 **정직하게 공개**한다. 내려갈수록
보상도 해골도 늘어난다. 질문은 하나뿐이다 — *지금 챙겨 나갈까, 한 층 더?*

## 왜 이 게임인가 — 세 번째 골격

[자석 구슬](../magnet-ball-sort/README.md)·페인트 믹스·[주차장 탈출](../parking-escape/README.md)은
**논리**의 게임이고(턴제·무위험·차분함), 병행 실험인 코멧 슬링(별도 브랜치)은
**반사신경**의 게임이다(실시간·즉사·속도). 논리의 대안이 반사신경만은 아니다 —
토치 다이브는 제3의 실력, **배짱(nerve)** 을 시험한다. 손은 느긋해도 심장은 빠르다.

| | 퍼즐 삼형제 | 코멧 슬링 | **토치 다이브** |
|---|---|---|---|
| 실력 | 논리 — 수를 읽는다 | 타이밍 — 손을 뗀다 | **판단 — 확률을 읽고 배짱을 낸다** |
| 시간 | 턴제, 위험 없음 | 실시간, 즉사 | **턴제인데 위험이 있다** — 생각할 시간은 무한, 대가는 실재 |
| 감정 | 정리의 만족감 | 속도의 긴장 | **욕심과 초조함** — "한 층만 더"의 유혹 |
| 구조 | 레벨 135개 + 별점 | 엔드리스 | **데일리** — 전 세계가 같은 날, 같은 던전, 하루 횃불 3개 |
| 실패 | 막다른 길 없음 | 죽으면 0.6초 재시작 | **잃는다** — 들고 있던 것만. 챙겨둔 것은 남는다 |
| 화면 | 파스텔 낮 | 네온 우주의 밤 | **횃불빛 지하** — 검은 흙, 호박색 불, 금화의 반짝임 |
| 조작 | 탭 (무엇을) | 홀드&릴리즈 (언제) | **탭 (열까) + 한 개의 큰 버튼 (나갈까)** |
| 소리 | 딸깍·퐁 | 휘익·쿵 | **쨍그랑·두둥** — 동전과 심장 박동 |

바뀌지 않은 것은 시리즈의 신조다: **설명하지 않는다**, 손맛이 먼저다,
공정함은 코드가 보증한다, 광고는 언제 안 띄울지가 더 중요하다.

## 루프

- 층마다 문 4개. 층 위의 pips가 이 층의 구성을 **있는 그대로** 보여준다 (🪙🪙💎💀)
- 문을 열면: 동전(+10×층수) · 보석(+40×층수) · 등불(엿보기 1회) · 해골(**들고 있던 것 전부 잃음**)
- 안전한 문을 열면 자동으로 한 층 아래로. 깊을수록 판돈도 해골도 커진다
- 열기 전에 언제든 **CLIMB OUT** — 들고 있던 것을 확정하고 지상으로
- 🏮 등불 하나를 태우면 문 하나를 미리 볼 수 있다 — 정보를 돈으로 사는 셈
- 하루 횃불 3개 = 다이브 3번. 오늘의 합계로 겨루고, 자정에 던전과 횃불이 리셋된다
- 횃불을 다 쓰면 무료 다이브 — 기록에는 안 들어가고, 내일 다시 진짜가 시작된다

## 설계 원칙: 설명하지 않는다 (pips가 곧 규칙서다)

튜토리얼 문구가 없다. 1층은 언제나 해골 0개라 첫 손맛은 공짜고, 2층부터 pips에
💀가 하나 등장한다 — 표시와 결과가 일치하는 경험 두어 번이면 규칙을 몸이 안다.
처음 한 번은 손가락(👆)이 첫 문을 가리키고, 3층까지 내려와 주머니가 찼는데
나가 본 적이 없으면 CLIMB OUT 버튼이 한 번 반짝인다. 그게 가르침의 전부다.

## 공정함은 코드가 보증한다

퍼즐 형제들이 솔버로 레벨을 보증하고 코멧 슬링이 생성 불변식으로 트랙을 보증했다면,
여기서는 **정직함 불변식**이 도박의 품위를 지킨다. 테스트가 검증하는 것:

- **표시된 구성 = 실제 내용물** — pips는 절대 거짓말하지 않는다 (시드 300개 × 25층)
- 1층은 해골 0개, **모든 층에 안전한 문이 최소 하나** (해골 상한 = 문 수 − 1)
- 보상 곡선과 해골 한계는 깊이에 대해 **단조 증가** — 내려갈수록 공평하게 험해진다
- 같은 (날짜 시드, 다이브 번호) = 같은 던전 — 전 세계가 같은 도박판에 앉는다
- 하루 3번의 다이브는 각각 배치가 다르다 — 외워서 이기는 길은 없다

죽음은 언제나 배짱의 결과지, 던전의 횡포가 아니다.

## 광고

다이브 도중에는 절대 안 뜬다. 죽거나 챙겨 나온 뒤의 전환 순간에만, 처음 5다이브는
무조건 무광고, 12초보다 짧았던 다이브 뒤에도 안 뜬다. 하루 3다이브 구조라 실전에는
거의 안 끼어들고 자연히 무료 다이브 구간에 몰린다. `?noads`로 끌 수 있다.

## 저장 키
