## 1. 플랫폼: 왜 Roblox인가 (확정)

**장점**
- 미국 6~12세가 **이미 모여 있는 곳** — 별도 앱 설치·마케팅 없이 노출 가능
- 무료 배포, 서버 인프라 Roblox가 제공 (서버 개발 비용 거의 0)
- 채팅 필터링·아동 보호·COPPA 대응을 플랫폼이 상당 부분 처리 → 안전 설계 부담 대폭 감소
- *Dress to Impress*가 같은 플랫폼에서 드레스업 수요를 이미 증명

**감수할 것 (알고 시작해야 함)**
- 수익 배분: 유저가 쓴 금액 중 개발자 몫은 실수령 기준 약 25~30% 수준 (Robux → 현금 환전 수수료 포함)
- IP·유저 데이터가 Roblox 플랫폼에 종속됨 — 나중에 자체 앱으로 옮기기 어려움
- 발견성(디스커버리)이 Roblox 알고리즘에 좌우 → **꾸준한 업데이트가 생명** (우리 "컴백" 구조가 여기에 유리)

**기술 스택**: Roblox Studio + Luau 스크립트. 의상은 Roblox 레이어드 클로딩(Layered Clothing) 시스템 활용.

> ⚠ v0.1의 "2D 정면 고정" 아트 방향은 폐기. Roblox는 3D 아바타 기반이므로 의상을 3D로 제작해야 함 → 3D 모델러(Blender + Roblox 파이프라인 경험자)가 팀에 필요.

## 2. 타겟: 6~12세 ★

하한을 6세로 내리면서 지켜야 할 것:
- 텍스트 최소화 — 아이콘 중심 UI, 큰 버튼
- 튜토리얼은 글 대신 화살표·반짝임 연출로
- 실패/패배 개념 없음 (경쟁 요소를 넣더라도 "탈락"이 아니라 "모두 보상, 1등은 추가 보상")
- 6~8세와 10~12세의 취향 차이는 의상 컨셉 폭으로 커버 (귀여운 컨셉 ↔ 걸크러시 컨셉)

## 3. 게임명 후보 (영어, K-pop 느낌)

Roblox는 검색·썸네일 노출이 중요하므로 "무슨 게임인지 이름에서 보이는 것"이 유리.

| 후보 | 느낌 | 비고 |
|---|---|---|
| **Comeback!** ★ 추천 | K-pop 팬이면 바로 아는 단어, 시즌 업데이트 구조와 일치 | Roblox 표기 예: `Comeback! K-pop Dress Up 🎤✨` |
| **Debut Stage** | "데뷔"라는 핵심 판타지 직접 표현 | `Debut Stage: K-pop Dress Up ✨` |
| **K-Star Closet** | 드레스업임이 이름에서 명확 | 검색 유리, 임팩트는 약함 |
| Bias! | 팬덤 용어(최애), 힙한 느낌 | 저연령(6~8세)은 모를 수 있음 |
| Lightstick | 응원봉 — K-pop 상징 | 드레스업 게임임이 안 드러남 |

> Roblox 관례: 제목에 `[NEW]`, 이모지, 업데이트 태그를 붙여 운영 (예: `[🌸SPRING] Comeback! K-pop Dress Up`).

## 4. 음악: 무료 음원 (확정)

- **1순위: Roblox Creator Marketplace의 무료 라이선스 음원** — Roblox가 배급사와 계약한 트랙들로, Roblox 게임 내 사용이 공식 허용됨. 비용 0, 저작권 리스크 0
- 보조: CC0(퍼블릭 도메인) 음원 — 단, Roblox는 외부 오디오 업로드에 제한·심사가 있으므로 마켓플레이스 우선
- 실존 K-pop 곡은 절대 사용 금지 (커버·리믹스 포함)
- "타이틀곡" 콘텐츠는 보류. 추후 성과가 나오면 오리지널 곡 제작 검토 (v2.0 이후)

## 5. 코어 루프 (Roblox 반영)

```
① 드레스룸: 캐릭터 꾸미기 (2~5분)
        ↓
② 무대 or 포토부스: 컨셉 배경에서 포즈 → 포토카드 생성
        ↓
③ 보상: 코인 + 챌린지 보너스
        ↓
④ 해금: 코인으로 새 의상·배경·포즈 구매 → ①로
```

- **소셜 훅(Roblox 강점)**: 같은 서버의 다른 유저 캐릭터를 구경하고 이모지 반응 가능 (자유 채팅은 Roblox 기본 필터에 위임)
- **주간 컨셉 챌린지**: "이번 주 테마: 레트로" — 무대에서 테마 의상 착용 시 보너스
- **컴백(6주)**: 새 컨셉 세트 + 무대 배경 교체 + 제목 태그 갱신 → Roblox 알고리즘 재노출

## 7. MVP 범위와 로드맵

**MVP (약 3~4개월 ★)** — Roblox라 서버 개발 불필요, v0.1 대비 단축
- 드레스룸 + 의상 약 100종 + 포토부스 + 미니 무대 + 코인 경제 + 일일 보상

**v1.1~**: 주간 챌린지, 첫 유료 세트, 첫 "컴백"
**v2.0**: 런웨이 투표 모드(Dress to Impress식 경쟁 — 단, 탈락 없는 저연령 친화 룰), 그룹(유닛) 만들기

**팀(안) ★**: 기획 1 / Roblox 개발(Luau) 1~2 / 3D 의상 모델러 1~2 / UI 아트 1

## 수익화 로드맵 (v0.3 확정 — Roblox 수익구조 기준)

> 원칙: **먼저 무료로 재미를 증명하고, 유저가 붙은 뒤에 결제를 붙인다.**
> Roblox는 유저 지출 $1당 개발자 실수령이 약 $0.20~0.28이므로, 매출의 핵심은 결제 설계가 아니라 리텐션(매일 다시 오게 만들기)이다.

**Phase 1 — 재미 증명 (런칭 ~ 첫 1-2개월)**
- 결제 요소 0. 목표는 평점·즐겨찾기·리텐션 지표 확보 (D1 30%+)
- 평점이 높아야 Roblox 알고리즘 노출이 살아남 → 초반 결제는 독
- 프리미엄 페이아웃(Premium Payout)은 이 단계에서도 자동 발생 — 플레이타임이 곧 첫 수익

**Phase 2 — 리텐션 구조 완성**
- 주간 컨셉 챌린지 + 첫 "컴백" 시즌 업데이트 가동
- 컴백 직후 CCU 스파이크와 복귀율을 측정 → 시즌 구조가 작동하면 Phase 3 진행

**Phase 3 — 수익화 시작 (지표 검증 후)**
- 1순위 **게임패스**: VIP 드레스룸, 독점 포즈팩 (1회 구매, 영구 혜택)
- 2순위 **개발자 상품**: 컴백 시즌 한정 컨셉 의상 세트 직접 구매
- 금지: 확률형 뽑기(가챠), 페이월로 기본 재미 잠그기
- DevEx 현금화: 누적 30,000 Robux(약 $105)부터 월 단위 환전

**측정할 것**: D1/D7 리텐션, 평균 세션, 즐겨찾기 전환율, (Phase 3 이후) 결제 전환율·ARPPU
