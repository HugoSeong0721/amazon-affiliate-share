## 1. 게임 개요

- **핵심 판타지**: "내가 만든 아이돌이 오늘 데뷔한다."
- 유저는 연습생을 데뷔시키는 프로듀서이자 스타일리스트. 캐릭터를 만들고, 컨셉에 맞게 스타일링하고, 포토카드를 찍어 컬렉션을 완성한다.
- 세션 길이 목표: 5~10분 (숙제 끝나고 자기 전에 한 판).

## 2. 왜 지금인가

- K-pop은 미국 초등학생 사이에서 주류 문화 (KPop Demon Hunters 흥행, 틱톡 댄스 챌린지, 스쿨 굿즈 문화).
- Roblox *Dress to Impress*가 증명한 것: 미국 아이들은 "꾸미고 자랑하기"에 강하게 반응한다. 그러나 K-pop 컨셉을 정면으로 다룬 드레스업 게임은 비어 있는 자리.
- 포토카드 수집 문화가 이미 아이들에게 익숙 → 게임 내 수집 구조와 자연스럽게 연결.

## 3. 코어 루프 (상세)

```
① 캐릭터 꾸미기 (2~5분)
   얼굴/헤어/의상/액세서리 선택
        ↓
② 포토카드 촬영 (1분)
   컨셉 배경 + 포즈 선택 → 카드 생성
        ↓
③ 보상 획득
   촬영 완료 코인 + 컨셉 챌린지 보너스
        ↓
④ 해금
   코인으로 새 의상/배경/포즈 구매
        ↓
   ①로 복귀 (새 아이템으로 다시 꾸미고 싶어짐)
```

**재방문 훅**
- 일일: 출석 보상 (무료 아이템 조각 → 7일 모으면 한 벌 완성)
- 주간: 컨셉 챌린지 ("이번 주 테마: 레트로" — 테마에 맞게 꾸미면 보너스)
- 시즌(6주): "컴백" — 새 컨셉 의상 세트 + 배경 + 포즈 출시

## 4. 핵심 시스템

### 4-1. 캐릭터 커스터마이징
| 부위 | MVP 수량 목표 |
|---|---|
| 피부톤 | 12종 (미국 시장 필수 — 어두운 톤 포함 균등 분포) |
| 얼굴형/눈/눈썹/입 | 각 8종 |
| 헤어스타일 | 20종 × 염색 팔레트 16색 |
| 상의 / 하의 / 원피스 | 각 15종 |
| 신발 | 10종 |
| 액세서리 (귀걸이·모자·안경 등) | 20종 |
| 소품 (마이크·응원봉·헤드폰) | 8종 |

**레이어 순서 (아래→위)**: 몸/피부 → 하의 → 상의 → 원피스(상·하의 대체) → 아우터 → 신발 → 액세서리 → 헤어(앞머리는 최상단 분리 레이어) → 손 소품

### 4-2. 포토카드 시스템
- 배경(무대·연습실·거리 등) + 포즈 + 프레임 선택 → 카드 생성.
- 카드는 앨범에 수집됨. 컨셉별 앨범 완성 시 한정 아이템 보상.
- 공유: MVP에서는 기기 저장(이미지 파일)만. 이후 버전에서 갤러리 공개 + 이모지 반응(자유 텍스트 없음).

### 4-3. 경제
- 단일 무료 재화(코인). 플레이로만 획득.
- 유료는 "컨셉 세트" 직접 구매(뽑기 없음). 무료 유저도 모든 시스템 이용 가능, 유료는 스타일 폭만 넓힘.

## 5. 아트 방향 ★

- 2D 정면 고정 (회전 없음 → 아트 비용 최소화), 5등신 세미치비.
- 밝고 채도 높은 파스텔+네온 믹스. K-pop 무대 조명 느낌의 이펙트.
- 무드보드: (레퍼런스 이미지 3장 첨부 예정)

## 6. 법적/안전 (미국 아동 타겟 필수)

- **COPPA**: 13세 미만 대상 → 개인정보 미수집 설계(MVP는 계정 자체가 없음), 타겟팅 광고 금지.
- **IP**: 실존 아이돌의 이름·얼굴·로고·곡 일절 사용 금지. 모든 캐릭터·음원은 오리지널. "K-pop 스타일"이라는 장르적 표현만 사용.
- **결제**: 보호자 게이트(구매 전 연산 문제 등) 적용.
- **커뮤니케이션**: 자유 채팅·자유 텍스트 입력 없음. 캐릭터 이름도 단어 조합 방식(Dress to Impress 방식).
- Apple Kids Category / Google Families 정책 체크리스트 별도 관리.

## 7. MVP 범위와 로드맵

**MVP (v1.0)** — 서버 없음, 오프라인 플레이
- 커스터마이징 전체 + 의상 약 120종 + 포토카드 촬영/앨범 + 코인 경제 + 일일 보상

**v1.1~**: 주간 컨셉 챌린지, 첫 유료 컨셉 세트
**v2.0**: 계정/서버 도입 → 갤러리 공개, 이모지 반응, 그룹 만들기(내 캐릭터 4명으로 유닛 구성)

**팀(안) ★**: 기획 1 / 2D 아트 2 / 클라 개발 1~2 / 파트타임 사운드 — MVP까지 4~5개월

## 8. 성공 지표

- D1 리텐션 35%+ / D7 15%+ (캐주얼 드레스업 상위권 기준)
- 세션당 포토카드 저장 1장 이상, 평균 세션 7분+
- 소프트런칭(미국 일부 지역 또는 캐나다)으로 지표 검증 후 확대
